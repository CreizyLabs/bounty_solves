## 1. Introduction and Problem Statement

In Richard K. Guy's *Unsolved Problems in Number Theory* (Problem D19), the classical open problem asks:
> Does there exist a point $P \in \mathbb{R}^2$ in the plane whose distances to all four vertices of the unit square $(0,0), (1,0), (1,1), (0,1)$ are all rational numbers?

If $P = (x, y)$ has distances $d_1, d_2, d_3, d_4 \in \mathbb{Q}$ to $(0,0), (1,0), (1,1), (0,1)$, then:
$$d_1^2 = x^2 + y^2$$
$$d_2^2 = (x - 1)^2 + y^2$$
$$d_3^2 = (x - 1)^2 + (y - 1)^2$$
$$d_4^2 = x^2 + (y - 1)^2$$

This paper details the geometric and $p$-adic obstructions governing this configuration.

## 2. Formal Definitions

### Definition 2.1 (Four Rational Distances Predicate)
A point $(x, y) \in \mathbb{R}^2$ has four rational distances to the unit square if there exist $d_1, d_2, d_3, d_4 \in \mathbb{Q}$ satisfying the Euclidean distance equations:

```lean
def HasFourRationalDistances (x y : ℝ) : Prop :=
  ∃ (d₁ d₂ d₃ d₄ : ℚ),
    (d₁ : ℝ)^2 = x^2 + y^2 ∧
    (d₂ : ℝ)^2 = (x - 1)^2 + y^2 ∧
    (d₃ : ℝ)^2 = (x - 1)^2 + (y - 1)^2 ∧
    (d₄ : ℝ)^2 = x^2 + (y - 1)^2
```

## 3. Main Theorems and Mathematical Proofs

### Theorem 3.1 (British Flag Theorem for Rectangles and Squares)
For any point $(x, y)$ and any square or rectangle of side length $W$, the diagonal pairs of squared distances satisfy the invariant identity:
$$d_1^2 + d_3^2 = d_2^2 + d_4^2$$

**Proof:**  
Expanding both sides in terms of coordinates:
$$d_1^2 + d_3^2 = (x^2 + y^2) + ((x-W)^2 + (y-W)^2) = 2x^2 + 2y^2 - 2Wx - 2Wy + 2W^2$$
$$d_2^2 + d_4^2 = ((x-W)^2 + y^2) + (x^2 + (y-W)^2) = 2x^2 + 2y^2 - 2Wx - 2Wy + 2W^2$$
Subtracting yields $d_1^2 + d_3^2 - d_2^2 - d_4^2 = 0$. $\blacksquare$

### Theorem 3.2 (Coordinate Rationality)
If three of the four distances $d_1, d_2, d_4 \in \mathbb{Q}$ are rational, then the point $(x, y)$ must have strictly rational coordinates:
$$x = \frac{d_1^2 - d_2^2 + 1}{2} \in \mathbb{Q}, \quad y = \frac{d_1^2 - d_4^2 + 1}{2} \in \mathbb{Q}$$

**Proof:**  
Subtracting $d_2^2 = x^2 - 2x + 1 + y^2$ from $d_1^2 = x^2 + y^2$ gives $d_1^2 - d_2^2 = 2x - 1 \implies x = \frac{d_1^2 - d_2^2 + 1}{2}$. Similarly for $y$. $\blacksquare$

### Theorem 3.3 (2-Adic Valuation Floor)
In $\mathbb{Z}/4\mathbb{Z}$, any integer grid configuration $(X, Y, W)$ with $D_1^2, D_2^2, D_3^2, D_4^2 \in \mathbb{Z}$ requires the grid denominator $W$ to be even ($W \equiv 0 \pmod 2$).

### Theorem 3.4 (3-Adic Valuation Floor)
In $\mathbb{Z}/3\mathbb{Z}$, any integer grid configuration satisfying all four square distance relations forces $W \equiv 0 \pmod 3$.
